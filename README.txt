MALOKA BIRTHDAY WEBSITE
=======================

الملفات:
- index.html          الصفحة الأساسية
- birthday.html       صفحة عيد الميلاد + 19 صورة
- styles.css          التصميم
- app.js              الحركة + الرسالة السرية + تخزين الصور
- main-song.mp3       أغنية الصفحة الأساسية
- birthday-song.mp3   أغنية عيد الميلاد

طريقة التشغيل:
1) افتح index.html.
2) لو هترفعه على Netlify / GitHub Pages / أي استضافة ثابتة، ارفع كل الملفات معًا كما هي.
3) الصور الـ19 لا تكون مرفوعة داخل الموقع مسبقًا. ملوكا تضيفهم بنفسها من صفحة عيد الميلاد.
4) الصور تحفظ داخل متصفح الجهاز باستخدام IndexedDB، وبالتالي هي خاصة بالجهاز والمتصفح الذي أضافها.
5) لو فتحت الموقع من جهاز أو متصفح آخر، الصور لن تنتقل تلقائيًا — وهذا مقصود للحفاظ على الخصوصية.
